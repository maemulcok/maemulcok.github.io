데이터 보관 안내

  • 무엇을 — 아이디(사무소명), 그리고 직접 등록한 매물 기록(동·호수, 상태, 금액, 소유주·임차인·연락처, 메모).
  • 왜 — 서버 장애나 실수로 지워졌을 때 되살리기 위한 정기 백업, 그리고 창업·운영상 장애 대응 목적입니다. 광고나 판매에 쓰지 않습니다.
  • 어디에 — 본인 계정만 열람할 수 있는 데이터베이스와, 관리자만 접근하는 암호화된 백업 파일(날짜별 JSON)에 보관합니다.
  • 관리자 열람·복구 — 장애 복구·백업·고객 지원을 위해 관리자가 데이터와 변경 이력을 열람할 수 있고, 실수로 지우거나 덮어쓴 호실 기록을 되살려 드릴 수 있습니다. 관리자가 복구한 내용도 변경 이력에 남습니다.
  • 얼마나 — 서비스 이용 기간 동안 보관하고, 탈퇴나 삭제를 요청하면 백업본에서도 지체 없이 지웁니다.
  • 다른 사무소 — 각 계정의 매물은 서로 보이지 않습니다. 서버 접근 규칙(RLS)으로 막혀 있습니다.

동의하지 않으면 가입할 수 없습니다. 문의는 서비스 관리자에게 해 주세요.

사용 안내

  • 내 매물만 — 로그인한 계정의 기록만 보이고 저장됩니다. 다른 사무소의 매물은 서버에서도 열리지 않습니다.
  • 빈 배치표에서 시작 — 101~106동 2,070세대의 호수·타입·면적·분양가가 깔려 있고, 상태와 메모는 직접 채웁니다.
  • 호실 더블클릭(폰은 한 번 탭) → 메모장이 뜹니다. 타입·면적·분양가·계약금(5%) 확인, 색상 변경, 금액·소유주·연락처·메모 작성.
  • 색상 — 기본 · 매매 · 전세 · 월세 · 보류·매매완료. 메모만 적어도 색은 바뀌지 않습니다.
  • 급매 (급) — 메모나 금액에 급매라고 적으면 호실 숫자 옆에 빨간 (급)이 붙습니다. 메모장의 (급) 급매 표시 버튼으로 직접 켜고 끌 수도 있습니다.
  • 상태 버튼 — 매매·전세·월세·보류·완료·급매·메모있음을 누르면 그 상태만 진하게 남습니다. 같은 버튼을 한 번 더 누르면 전체로 돌아옵니다.
  • 자동 저장 — 입력하는 대로 계정에 저장되어 PC와 폰에 그대로 이어집니다.
  • 단축키 — F 맞춤 · 0 100% · + / − 확대·축소 · / 검색 · Esc 닫기
